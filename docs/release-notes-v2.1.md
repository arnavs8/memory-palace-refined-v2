# Memory Palace 2.1

- Exam-focused cloud AI analysis with editable concepts, practice questions, source quotations and topic coverage.
- In-app OpenRouter key creation instructions, live free-model selection, encrypted key storage and explicit document-sharing consent.
- Detailed house and carnival environments with 26 bundled CC0 models, four themed zones, and stable procedural object placement.
- Preserved existing palace layouts and improved idle rendering.
- Includes the 12-slide project presentation.

Download Setup for installation, or the portable executable. This release is unsigned. Existing installations do not update automatically.

AI setup: open Free AI setup in the app, follow the OpenRouter key link, paste your key, and check the connection. Free models have quotas; Qwen appears only if a free endpoint is available. No paid fallback is configured.

Validation: 16 unit/contract tests, four browser workflows and packaged desktop smoke test passed. AI integration used a mocked provider; real model quality has not yet been evaluated with a user key. Scanned PDFs still require OCR outside this app.
