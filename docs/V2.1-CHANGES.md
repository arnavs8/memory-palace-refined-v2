# Version 2.1

## Semantic study preparation

- Free cloud AI through OpenRouter with in-app key-generation instructions and browser links.
- Encrypted API key storage, connection validation, live free-only model selection, quota display when available, cancellation, and explicit document-sharing consent.
- Two-stage source-grounded concept analysis and synthesis, exam/course objectives, editable practice questions, importance rationales, exact source evidence, and a coverage summary.
- Separate manual import, with no claim that it performs semantic analysis.

## Detailed, persistent procedural environments

- New palaces use four furnished, named zones: a jade library, amber study, blue salon and terracotta gallery, or four themed market pavilions in the carnival.
- 26 bundled detailed glTF assets, including plants, chess pieces, books, clocks, a mirror and hanging chandeliers; textured floors, trim, panelling, framed art, curved striped awnings, festoon lighting, and image-based material lighting.
- Seeded placement variation within safe furnished bays. AI concept categories influence prop assignment. Central routes and doors stay clear, and all generated placements are saved in backups.
- Old palaces retain their original locations and old scene layout to avoid breaking learned associations. Create a new palace to use the new environments.
- Static shadow reuse and idle rendering for rooms; animation pauses while studying a card.

The app still uses Three.js inside Electron. This release does not claim a Unity migration or photorealistic, scanned whole-building environments. More environmental art and hardware performance tuning remain worthwhile.

## Verification

16 core, analysis-contract and layout tests cover citation rejection, free-only gating, synthesis validation, cancellation, stable placement, collisions and backup preservation. Browser and desktop workflows are checked separately. Live authenticated cloud quality requires the user's own API key; mocked inference tests are not presented as real-model evaluations.
